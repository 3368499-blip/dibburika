# דיבוריקה · משחקי שפה ודיבור

אתר משחקים לקלינאיות תקשורת ולהורים. בעברית, מותאם לטלפון, לטאבלט ולמחשב.

- **דף הבית:** `index.html`. המשחקים מסודרים לפי תחום טיפול: אוצר מילים, תחביר, היגוי.
- **הדשבורד:** `dashboard.html`. הקוד הראשון הוא **1234**, וכדאי להחליף אותו מיד.

## המשחקים
| משחק | תחום | מה עושים |
|---|---|---|
| **מסלול הכוכבים** `games/path.html` | אוצר מילים, היגוי | זורקים קובייה, וכל כוכב שנוחתים עליו מגלה מילה: תמונה, כתב והקראה |
| **בועות קסומות** `games/bubbles.html` | אוצר מילים, היגוי | יורים על בועות, ובועה עם כוכב מגלה מילה |
| **זיכרון משפטים** `games/memory.html` | תחביר | זיכרון עם משפטים פשוטים (ילד אוכל תפוח / ילדה אוכלת תפוח), 6 עד 24 קלפים, "משפטים דומים", שני שחקנים |
| **המפלצת הרעבה** `games/monster.html` | היגוי | כל חזרה על מילה מאכילה את המפלצת. הילד לבד או מבוגר מדרג (נכון / כמעט / עוד לא), הקלטה ושמיעה עצמית |
| **עולם המילים** `games/vocab.html` | אוצר מילים | איפה זה, מה זה (שיום), זוגות, מי לא שייך |

### ממה משחקים
כל משחק בוחר תוכן מאותו רכיב (`assets/content.js`):
- **אוצר מילים:** 497 מילים ב־20 נושאים
- **חפץ ושימוש (מתקדמים):** 56 זוגות, למשל מפתח · פותחים, מגהץ · מגהצים
- **משפטים:** 344 משפטים שנבנים אוטומטית עם התאמה במין ובמספר
- **היגוי:** 351 מילים לפי 10 צלילים (ר, ל, ש, ס, ז, צ, ק, ג, ח, ת) ומיקום (תחילת מילה, אמצע, סוף). הצליל מודגש במילה
- **רשימה שלי:** מקלידים מילים לתרגול ושומרים כרשימה

### שליחה להורה
בכל מסך הגדרות יש כפתור **"שליחה להורה"**. הוא יוצר קישור (גם לוואטסאפ) שפותח את המשחק עם בדיוק ההגדרות שבחרתם,
וההורה רק לוחץ "מתחילים". זה עובד כבר עכשיו, גם בלי מאגר משותף.

| תוצאות ומעקב | כל מפגש לפי מטופל, אחוזי הצלחה, מילים שכדאי לתרגל, ייצוא לאקסל |
| הגדרות וגיבוי | שם האתר, מהירות הקראה, צלילים, גיבוי ושחזור |

## חשוב לדעת: איפה הנתונים נשמרים
כרגע הכל נשמר **בדפדפן שבו עובדים**. מילים, משתמשים ותוצאות שמוסיפים במחשב אחד
לא יופיעו אוטומטית בטלפון של הורה. אפשר להעביר הכל בקובץ גיבוי (הגדרות וגיבוי).

**השלב הבא:** חיבור למאגר משותף (Firebase, חינמי, כמו בפרויקטים האחרים במאגר).
אחרי החיבור כל שינוי בדשבורד יגיע מיד לכל המשתמשים, והקודים יעבדו מכל מכשיר.
כל השמירה עוברת דרך `assets/core.js`, כך שהחיבור לא ידרוש שינוי במשחקים.

## העלאה לאוויר
**GitHub Pages:** Settings ← Pages ← Deploy from a branch ← בוחרים את הענף ואת `/(root)`.
הכתובת תהיה `https://3368499-blip.github.io/dibburika/`.
אפשר לחבר דומיין משלכם באותו מסך (Custom domain), או להעלות את התיקייה כמו שהיא לכל אחסון.
אין שלב בנייה: אלה קבצים רגילים.

## עבודה משותפת
- מוסיפים שותפים ב־GitHub: Settings ← Collaborators. כל אחד יכול להציע שינויים.
- **מילים לכולם:** עורכים את `data/words.js` (פורמט `מילה:אימוג׳י:רמה`).
  מילים שמשתמשים מוסיפים או עורכים בדשבורד נשמרות בנפרד, אז עדכון של הקובץ לא דורס אותן.
- **משחק חדש:** קובץ חדש בתיקייה `games/` ורשומה ב־`data/games.js`. הוא מופיע אוטומטית בדף הבית, בדשבורד ובהרשאות.

